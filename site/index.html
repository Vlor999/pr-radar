Confidentialité

Aucun serveur : l'app parle seulement à github.com et api.github.com, depuis votre machine. Le jeton reste dans le trousseau du système (Trousseau macOS, Gestionnaire d'identification Windows, Secret Service sous Linux), et il n'y a aucune télémétrie.

Questions fréquentes

Quels droits l'app demande-t-elle ?

Deux scopes : repo pour lire les PR des repos privés et répondre aux discussions, read:org pour lister les repos de vos organisations. Avec un jeton d'accès personnel (classic), cochez les mêmes : repo et read:org.

Mon organisation utilise le SSO SAML

Avec le device flow, ouvrez d'abord une session SSO sur l'org, puis validez le code ; si l'org restreint les apps tierces, un admin doit approuver PR Radar. Avec un jeton d'accès personnel, ouvrez-le dans les réglages GitHub et cliquez sur « Configure SSO » pour l'autoriser sur l'org. Sinon, les repos de cette org n'apparaissent pas.

GitHub Enterprise est-il pris en charge ?

Pas encore : l'app parle uniquement à github.com et api.github.com.

Comment se font les mises à jour ?

L'app vérifie la dernière release GitHub au démarrage puis toutes les 6 heures. Chaque mise à jour est signée : l'app vérifie la signature avant d'installer, puis redémarre.

À quelle fréquence l'app interroge-t-elle GitHub ?

Toutes les 5 minutes par défaut, réglable de 1 à 30 minutes ou en manuel. Les requêtes comptent dans votre quota d'API GitHub habituel.
