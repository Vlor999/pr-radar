Privacy

PR Radar only talks to GitHub, to your GitHub Enterprise server if you add one, and to Slack if you connect it. No server: tokens live in your OS keychain, Slack tokens are read-only and rotate automatically (they expire every 12 hours), and you can revoke them at any time. Your messages never leave your machine.

The app also contacts github.com to check for updates (your IP address and app version) and loads avatars from GitHub. Slack messages are searched and read on your machine only; nothing is sent to us or anyone else.

The local MCP server is off by default. Once turned on, it answers only on your machine, through a socket that only your user account can open, and in read-only mode: agents read what the app already shows, no tool writes to GitHub or Slack, and nothing leaves your machine.

The local web version is off by default. Once turned on, it listens on 127.0.0.1 only, out of reach of other devices on your network. The link opened by the app carries a single-use ticket valid for 60 seconds, exchanged for a session cookie set by the local app, not by this website (HttpOnly, SameSite=Strict), and “Sign out browsers” closes every session. Other websites can't call it (Host and Origin checks, no CORS). GitHub and Slack requests go through the app, to the same allowed hosts: nothing leaves your machine beyond the usual GitHub and Slack API calls.

This website is hosted by GitHub Pages, which logs visitors' IP addresses. Your browser asks api.github.com for the latest release. This website sets no cookies and has no analytics: only your language choice is kept in your browser (localStorage). During Slack sign-in, the one-time code briefly passes through a page of this site, which stores nothing; it is unusable without the key kept in the app.

Frequently asked questions

What permissions does the app ask for?

Two scopes: repo to read PRs in private repos and reply to discussions, read:org to list your organizations' repos. With a personal access token (classic), check the same ones: repo and read:org.

My organization uses SAML SSO

With the device flow, start an SSO session on the org first, then confirm the code; if the org restricts third-party apps, an admin must approve PR Radar. With a personal access token, open it in your GitHub settings and click “Configure SSO” to authorize it for the org. Otherwise, that org's repos won't show up.

Is GitHub Enterprise supported?

Yes, with a personal access token: in Settings, add an account with your server's host. "Sign in with GitHub" works on github.com only.

How do updates work?

The app checks the latest GitHub release on startup, then every 6 hours. Every update is signed: the app verifies the signature before installing, then restarts.

How often does the app poll GitHub?

Auto by default: the interval adapts to your remaining GitHub quota (between 1 and 15 minutes, keeping 20% of the hourly quota in reserve). Or a fixed interval from 1 to 30 minutes, or manual. Requests count against your usual GitHub API quota.

Does my Slack admin need to approve it?

Yes, if your workspace requires it. Click Connect and Slack offers to request the installation.

How do I connect my AI agent (Claude Code, Codex, Cursor…)?

Click the plug icon next to the gear and turn the server on. In the Setup section, pick your client (Claude Code, Claude Desktop, Antigravity, Codex, Cursor, Devin Desktop, Gemini CLI, VS Code, Windsurf, Zed or any other): it gives the command or the config to paste, with the real path of the app, for example claude mcp add --scope user pr-radar -- '/Applications/PR Radar.app/Contents/MacOS/pr-radar' --mcp. PR Radar must be running. macOS and Linux only for now.

How do I open PR Radar in my browser?

Click the globe in the header: it starts the local server if needed and opens the web version in your browser, on http://127.0.0.1:14200/ by default (port changeable in Web settings). The chevron next to it shows the status and leads to Web settings (port, start and stop, sign out browsers). While the web version is running, the menu bar or tray icon also offers “Open in browser”. PR Radar must keep running: closing the window keeps it in the menu bar or tray, when your system shows one. A bookmark works only while the app and the web server keep running: restarting the app, stopping the server, changing the port or “Sign out browsers” ends the session; reopen it from the globe. Account sign-in, Slack connection, updates and uninstall stay in the desktop app.
