Premier lancement

L'app n'est pas signée : un certificat payant n'a pas de sens pour un outil gratuit. Le système vous le signale une fois, voici comment passer.

macOS

Clic droit sur l'app, Ouvrir, puis Ouvrir. Ou, dans le terminal :

xattr -dr com.apple.quarantine "/Applications/PR Radar.app"

Windows

SmartScreen : Informations complémentaires, puis Exécuter quand même.

Linux

Rendez l'AppImage exécutable, puis lancez-la :

chmod +x PR*Radar*.AppImage

Connexion à GitHub

Deux options : le device flow (l'app affiche un code à saisir sur github.com) ou un jeton d'accès personnel. Le jeton reste dans le trousseau du système. Pas de backend, pas de télémétrie : les requêtes partent de votre machine vers GitHub, rien d'autre.

Fonctions

  • Arbre des PR et des stacks
  • Statut review, CI, conflits
  • Discussions non résolues avec le code, réponse directe
  • Filtres, recherche, tri
  • PR prêtes à merger
  • PR inactives
  • Nouveau depuis la dernière visite
  • Calendrier des merges (mois, semaine, jour)
  • Repos par organisation
  • Notifications système
  • Thème clair et sombre
  • Raccourcis clavier
