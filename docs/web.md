# Local web version

Off by default. Runs only while the app runs.

- Click the globe in the header: the app starts its local server if needed and opens `http://127.0.0.1:14200/` (default port, changeable in Web settings).
- The chevron next to the globe shows the status and leads to Web settings: port, start and stop, "Sign out browsers".
- Account sign-in, Slack connection, updates and uninstall stay in the desktop app.

Security model: see [privacy.md](privacy.md#local-web-version).
