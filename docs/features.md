# Features in detail

The README lists the main features. This page has the details.

## Dashboard

- PR tree per repo, with "depends on / blocks" stacks.
- Repo picker per organization.
- Review, CI and conflict status on each card. Click the CI badge to see the CI jobs per workflow and re-run the failed ones.
- Other people's PRs where you are assigned, mentioned or involved appear in the tree with the reason.
- Automatic refreshes reread only the PRs that changed. A status dot next to Refresh shows the result of the last one.

## Keyboard

- Command palette: `⌘K` / `Ctrl+K`.
- `/` search, `j` / `k` next and previous card, `o` open the PR on GitHub, `e` expand the card, `d` light / dark theme.

## Settings

- Settings are grouped by category, with a typo-tolerant search.
- Do not disturb mutes notifications for 1 h or until tomorrow. It is also in the tray menu.
- Diagnostics: a local activity log (redacted, with retention settings) and crash reports you review before sending.

## Menu bar and tray

On macOS, closing the window or pressing `⌘Q` keeps the app running in the menu bar. Quit it from the tray menu.
